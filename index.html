Chapters 5 & 6 — Linear Functions, Quadratics & Polynomials

Chapter 5 – Linear Functions: Applications

Linear Equation & Function

A linear function has the form y = mx + b, where the graph is a straight line.

y = f(x) = mx + b

m = slope (rate of change)  |  b = y-intercept

Slope formula: m = (y₂−y₁)/(x₂−x₁)

Common mistake: Confusing slope sign — negative slope means decreasing function.

Cost, Revenue & Profit Functions

Total Cost: C(x) = cx + F    (c=variable cost/unit, F=fixed cost)
Revenue: R(x) = px    (p=selling price/unit)
Profit: P(x) = R(x) − C(x) = (p−c)x − F

These are linear when price and variable cost per unit are constant.

Exam tip: Always identify fixed vs variable costs before writing C(x).

Break-Even Analysis

Break-even: R(x) = C(x)  →  (p−c)x = F  →  x* = F/(p−c)

Contribution margin per unit = p − c (selling price minus variable cost).

Break-even quantity x* is where profit = 0. Below x*: loss; above x*: profit.

Business example: Factory with fixed costs $40,000, variable cost $12/unit, selling at $20: x* = 40000/8 = 5,000 units.

Demand & Supply Functions

Demand: q = a − bp   (downward sloping: quantity falls as price rises)
Supply: q = c + dp   (upward sloping: quantity rises as price rises)

Market Equilibrium: Set demand = supply and solve for equilibrium price p* and quantity q*.

Exam tip: At equilibrium, both buyers and sellers agree on price. Substitute p* back to find q*.

Mathematical Modeling with Linear Functions

Identify known variables, define the function, and interpret the slope as a rate of change.

Two-point form: find slope first, then use y − y₁ = m(x − x₁) to get the equation.

Chapter 6 – Quadratic & Polynomial Functions

Quadratic Function

f(x) = ax² + bx + c    (a ≠ 0)

Graph is a parabola. Opens upward if a > 0 (minimum), downward if a < 0 (maximum).

Vertex: x = −b/(2a)    y_v = f(−b/(2a))
Axis of symmetry: x = −b/(2a)

Solving Quadratic Equations

Quadratic Formula: x = [−b ± √(b²−4ac)] / 2a
Discriminant: Δ = b²−4ac

Δ > 0: two real roots  |  Δ = 0: one repeated root  |  Δ < 0: no real roots

Common mistake: Forgetting to check the sign of 'a' before declaring max/min.

Revenue & Profit Optimization

When price or demand is a linear function of quantity, Revenue becomes quadratic:

If p = a − bq, then R(q) = p·q = (a−bq)q = aq − bq²

Maximum revenue at vertex: q* = a/(2b), R* = a²/(4b)

Profit: π(q) = R(q) − C(q) — maximize by finding vertex

Exam tip: Always verify the vertex gives a maximum (a < 0 for the quadratic).

Polynomial Functions

f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀

Degree = highest power. Leading coefficient determines end behavior.

Even degree, positive leading coeff → both ends up. Odd degree → opposite ends.

Number of real zeros ≤ degree of polynomial.
